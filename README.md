# ロボットシステム学-課題1
数字であなたの運勢を占う!

# 概要
このプログラムは、実行後に入力された生年月日の8個の数字から、1~9までの9つの数字をランダムに排出するプログラムです。あなたの今日のラッキーナンバーを提示します。

打ち込まれたすべての数字を合計し、その合計が1~9のいずれかになるまで繰り返します。

例:1990年12月31日生まれの人の場合
→19901231と入力
→1+9+9+0+1+2+3+1=26 
→2+6=8

# 使い方
実行方法の例
<pre>
$ echo "20051110" | ./luckynumber
</pre>

実行結果の一例
<pre>
1
</pre>


# インストールの手順
1:gitをインストールしていない場合は、以下のコマンドを入力してください。
<pre>
$ sudo apt install git
</pre>

2:リポジトリをクローンしてください。
<pre>
$ git clone https://github.com/Kotaroa-Maverick/robosys2025.git
</pre>

3:ディレクトリを移動させてください。
<pre>
$ cd robosys2025
</pre>

4:実行権限を獲得してください。
<pre>
$ chmod +x luckynumber
</pre>

5:「使い方」にある実行コマンドを入力してください。echoの後ろに、
生年月日8桁を書き込んでください。
<pre>
$ echo "20051110" | ./luckynumber
</pre>
