# ロボットシステム学-課題1
数字であなたの運勢を占う!

# 概要
このプログラムは、実行後に入力された生年月日の8個の数字から、1~9までの9つの数字をランダムに排出するプログラムです。あなたの今日のラッキーナンバーを提示します。

打ち込まれたすべての数字を合計し、その合計が1~9のいずれかになるまで繰り返します。

例:1990年12月31日生まれの人の場合
→19901231と入力
→1+9+9+0+1+2+3+1=26 
→2+6=8

# 使い方
実行方法の例
<pre>
$ python3 luckynumber
</pre>

実行結果の一例
<pre>
ラッキーナンバー計算機へようこそ
あなたの生年月日を8桁で入力してください (例: 19901231): 20051110

入力された生年月日: 20051110
**あなたのラッキーナンバーは 1 です！**
</pre>
